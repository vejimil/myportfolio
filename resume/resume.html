World of Words · Solo · Language-learning web platform world-of-words.org
  • Planned, designed, and built a vocabulary platform for beginner learners of Japanese, French, and Spanish (up to ~A2), from content structure to frontend.
  • Replaced fixed word lists with generated quizzes: randomized items from word sets, JLPT-style questions for Japanese, and natural language pairings (KO–JA, EN–FR, EN–ES).
  • Turned review into play by reworking a typing-game format into meaning-recognition mini-games with drag/click input; tuned quiz and game layouts for short mobile sessions.
Triends · Two-person team · Co-op 2D adventure (Phaser) GameAIfy asset contest
  • Shaped the core contrast — an astronaut using tools and a plant companion using light — so progress depends on coordination rather than duplicated actions.
  • Designed and implemented the light-puzzle section as a three-stage learning curve: light routing → beam splitting → coordinated play.
  • Refined AI-generated sprite drafts frame by frame into readable character and plant animations through manual pixel editing.
Arcade Games · Personal · Local two-player games Python → JavaScript
  • Built one-screen, two-player games for an offline environment and tuned timing, feedback, and balance from direct player reactions.
  • Ping-Pong Smash adds a timed smash to Pong for faster, riskier rallies; Space Duel grows a shape-based shooter with pickups and level-based bullet patterns.
  • Ported both games to the browser so visitors can play them on the portfolio.
